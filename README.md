# Paradigmas de Programação

Este repositório em Java é destinado ao curso de "Paradigmas de Programação da UNISAL".

## Estrutura do Projeto
- `herenca/` - Código-fonte do projeto.
## Requisitos
- **Java Version**: JDK 11 ou superior
- **Build Tool**: Maven ou Gradle

## Como Executar/Compilar Exemplos
Para compilar e executar os exemplos, use o comando apropriado para o seu build tool:
- **Maven**: `mvn clean install`
- **Gradle**: `./gradlew build`

## Diretrizes de Contribuição
1. Fork o projeto.
2. Crie uma branch para a sua feature (`git checkout -b feature/MinhaFeature`).
3. Faça suas alterações e commit (`git commit -m 'Adiciona minha feature'`).
4. Envie para o repositório remoto (`git push origin feature/MinhaFeature`).
5. Crie um Pull Request.
